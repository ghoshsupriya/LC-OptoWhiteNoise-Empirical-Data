Empirical data for transient LC noradrenergic control of perception

Manuscript: Ghosh, S. and Maunsell, J. H. R., Transient noradrenergic signals act as online controllers of perceptual computation.


This repository contains the experimental datasets used to investigate the temporal influence of optogenetic white-noise stimulation of locus coeruleus (LC) neurons on visual discrimination in two rhesus macaques. It includes trial-by-trial behavior and stimulation histories, processed population behavioral/stimulation profiles, and measured LC optical impulse-response data.


Files

empirical_data/`:

1. empiricalWN_Pos03.mat: Poseidon (monkey P): retained single-trial behavioral data and sample-aligned LC white-noise stimulation, with session and trial ordering.
Current- and preceding-trial behavioral GLMs; signal-detection analysis; LC timing.

2. empiricalWN_Shr03.mat: Sherlock (monkey S): equivalent single-trial dataset. Same analyses.

3. data_OptoKernel_LC_Pos_01.mat: Poseidon: processed session/population behavioral and LC stimulation profiles.
Experimental characterization, behavioral reverse correlation, single-trial analyses.

4. data_OptoKernel_LC_01.mat: Sherlock: corresponding processed session/population profiles. Same analyses.

5. OptoImpulseFunction_LC.mat: Processed neuronal responses to optical stimulation, including LC impulse-response information for both animals. Physiological calibration of LC activation timing.


Data structure and conventions
1. Trial-level datasets (empiricalWN_*.mat)
These files are expected to contain the following key fields, based on the empirical-data preparation and analysis scripts:

empiricalWN.trialTable: one row per retained experimental trial, containing the experimental session and chronological trial identifiers, task and stimulus conditions, stimulation indicator, behavioral outcome/correctness, and trial-eligibility flags. Trial order within each session is retained. The preparation scripts select valid blocks and retain ineligible trials within those selected blocks using flags; the data are not a complete archive of every original session trial.
empiricalWN.WN: trial-by-time matrix of sample-aligned optical stimulation at 1ms resolution over −400 to +400 ms relative to sample onset (800 samples, endpoint excluded).
empiricalWN.WN25: legacy field name for the binned stimulation predictor. In the final extraction used by the current behavioral GLM and SDT scripts, this field contains 160 bins of 5 ms, not 25 ms bins.
empiricalWN.config: timing and extraction conventions, including stimulation-window limits and bin duration, when present.

Relevant trialTable variables include sessionNumber, trialNumber, blockNumber, glmEligible, stimTrial, correct, isMatchTrial, testLoc, oriDiffAtTestDeg, sampleOriAtTestDeg, and meanPowerMW. Session boundaries must be respected when constructing history predictors. In the current analysis code, contralateral testLoc is encoded 1 for Poseidon and 0 for Sherlock.

Data structure and conventions
2. Population behavior files (data_OptoKernel_LC_*.mat)
These files are generated by the population SDK analysis scripts and are expected to contain a structure named data. They hold derived experimental behavioral/stimulation profiles grouped by session and task conditions, rather than original trial files.

Data structure and conventions
3. LC impulse-response file (OptoImpulseFunction_LC.mat)
The timing-analysis scripts load the top-level structure optoImpulse, accessing animal-specific (pos, shrl) LC neuronal impulse-response functions and time vectors.

Example: Loading the data in MATLAB

S = load(fullfile('empirical_data','empiricalWN_Pos03.mat'), 'empiricalWN');
E = S.empiricalWN;
T = E.trialTable;

% Verify alignment between trial metadata and white-noise inputs
assert(height(T) == size(E.WN, 1));
assert(height(T) == size(E.WN25, 1));
assert(size(E.WN, 2) == 800);

% Final empirical GLM/SDT analyses use 5-ms bins despite the WN25 name
assert(size(E.WN25, 2) == 160);

% Select analysis-eligible trials without reordering or joining sessions
idx = logical(T.glmEligible);
X = double(E.WN25(idx, :));
Tselected = T(idx, :);


Do not concatenate session histories without resetting history predictors at session boundaries. Confirm any model-specific additional eligibility restrictions from the corresponding analysis script.

Derivation and exclusions:
The two `empiricalWN_*.mat` files are generated from the original behavioral SDK session files by `dataOrganize_for_glm_wn_pos.m` and `dataOrganize_for_glm_wn_sherl.m`. The two `data_OptoKernel_LC_*.mat` files are generated by the corresponding `SDKAnalysis_Population_*` scripts. `OptoImpulseFunction_LC.mat` is produced from optical-stimulation neuronal PSTHs by `OptoImpulseFunction_LC.m`.
